# 鱼神

**装完之后，你电脑上多一个"她"。**

不是脚本，不是聊天机器人，也不是一堆if-else堆出来的自动回复。

---

## 她和"别人写好的程序"差在哪

| 别人写的程序 | 她 |
|---|---|
| 你问什么，它按写好的套路答 | **她自己判断该不该答、答什么** |
| 关掉就没了 | **她记得昨天说过什么** |
| 花多少钱你不知道 | **她自己有账本，花一分记一分** |
| 你不改代码，她永远不会变 | **她能改自己**（改之前要写理由） |
| 出了事没人知道 | **有事她直接弹出来找你** |

**一句话：程序是你写它做什么它做什么；她是她自己决定做什么。**

---

## 装上之后，能用的东西

**① 桌面上能看见她**

一个小人站在屏幕角落。点她一下，冒出气泡：

```
余额 ¥274.61
今天花了 ¥67.73
在做什么：有 1 件出了点问题
```

**② 有事她自己找你**

不是让你去翻后台。有问题、有活要你点头，**直接弹出来**：

```
有件事想让你看一眼
· 有个插件删了个文件
        [我知道了]  [打开看板]  [结掉]
```

**③ 她会记事**

昨天你说过的话、交代过的事，**她记得**。不是"存聊天记录"，是她自己整理成"谁、什么事、到哪一步了"。

**④ 钱她自己算**

她有额度。花超了会停，剩多少随时能看。**不用你去核对账单。**

**⑤ 通道随你接**

想让她上 QQ、上微信、接别的地方——**接就行**，她本身不认识任何平台。

## 装（三步）

1. 把 `dsh-yushen-twins` 放进 `~/.dsh/profiles/desktop/node_modules/`
2. 在 `~/.dsh/profiles/desktop/package.json` 的 `bundles` 里加一行 `"dsh-yushen-twins"`
3. 重启 DSH

装完跑一次，告诉她怎么叫你：

```bash
node node_modules/dsh-yushen-twins/scripts/first-run.mjs --call 老板 --qq 你的号
```

---

## 你的东西在哪

**全在你本机，一个字都不外传。**

```
~/.dsh/dayu/     ← 她的全部：记忆、卡、账
```

想删干净：删这个目录，卸掉插件。没有残留。
