# dsh-yushen-popup · 鱼神弹窗

卷轴画卷式的提醒弹窗。**独立插件**，不依赖鱼神双子星，任何插件都能调。

## 它长什么样

- **蓝版**：深海蓝水晶框，平时用
- **红版**：红金水晶框，要紧的事用
- 开场是**卷轴**：两翼并拢 + 中间贝壳轴心 → 点轴心展开（或按设置直接展开）
- 内容多时内部滚动；字随弹窗缩放（cqw）
- 关闭有四种：点「好/知道了」、按 **Esc**、点弹窗外面的暗色区域、点「稍后」（推迟，不是关）。开了「关闭后保留悬浮窗」时，确认键会收成小画卷留在角落，再点又展开。

## 怎么用

任何插件/页面里：

```js
window.__yshenImportantPopup({
  theme: 'blue',            // 'blue' | 'red'
  badge: '要紧',            // 左上角小标签
  title: '真要重启？',      // 标题
  body: '重启会断开一下……', // 正文（可长，内部滚动）
  confirmText: '知道了',    // 主按钮
  // cancelText: '稍后',    // 有第二个选择时才给；不给就只出一个键（看完关掉）
  autoExpand: false,        // true = 直接展开，不走卷轴
  items: [                  // 多条时传数组，弹窗显示列表
    { badge: '出问题', title: '备份停了', body: '3 小时没动，要查吗？' },
    { badge: '有人找你', title: '大鱼在问', body: '今天还开播吗？' },
  ],
})
```

返回 `Promise<boolean>`：确认 true、取消 false。

**按钮规则**（2026-11-11 起）：不给 `cancelText` 就只有一个键，作用是"看完关掉"，不会被收成悬浮画卷；真有两个选择（比如「稍后」）才出两个键。

让后台直接推（不用刷新页面）：

```
POST /yushen-popup/preview
{ "theme": "red", "title": "...", "body": "...", "badge": "..." }
```

前端用**长轮询**（`GET /yushen-popup/wait`，宿主把请求挂着，最多 20 秒）：有东西立刻弹出，空闲时不会定时空转。宿主太老没有这个路由时，自动退回定时轮询。

## 后台（弹窗控制台）

侧边栏 **✦ 弹窗** 点进去：

| 分类 | 管什么 |
|---|---|
| 展示方式 | 直接通知 / 卷轴仪式、紧急事件直接跳仪式、点空白行为 |
| 手感 | 点击水声、缩小画卷可拖、记住位置、悬停反馈 |
| 主题与事件 | 蓝 / 红 / 默认（蓝平时红警醒）、红蓝图范围、事件→颜色、哪些事件弹 |
| 字体美化 | 字体、字号、正文色、强调色、深浅、还原默认 |
| 用法 | API 示例 |

右上角有「重新加载界面」——改了客户端代码点它，等于刷新页面（DSH 打包版没有 Ctrl+R）。

配置存在 `~/.dsh/dsh-yushen-popup/config.json`。

## 安装

已装在本机 profile 里。换机器时：

1. 把本目录放到喜欢的位置；
2. 在 `~/.dsh/profiles/desktop/package.json` 的 `dependencies` 加：
   `"dsh-yushen-popup": "link:<插件目录的绝对路径>"`
3. 在 `dsh.profile.bundles` 数组里加 `"dsh-yushen-popup"`；
4. `pnpm install`；
5. 重启 DSH。

**注意**：第 3 步最容易漏——只装依赖不登记 bundles，插件不会被加载（路由 404、侧边栏没图标）。

## 出厂默认值（2026-11-11 定）

| 开关 | 默认 | 说明 |
|---|---|---|
| 备份完成提醒 | **关** | 备份是鱼神自己的机制，别人不一定有 |
| QQ / B站 来源 | **关** | 要接的话在后台勾上 |
| 本机来源 | 开 | |
| 每轮成本提醒 | 关 | 气泡里已经显示花费，不必每轮弹 |
| 累计花费 / 容量提醒 | 开 | 阈值在后台可调 |
| 小黑板 | 开（空白） | 手写事项存 localStorage |
| 同类提醒去重 | 10 分钟 | 同一件事只弹一条，其余次数写进正文 |

## 素材

`assets/popup/blue|red/` 各 6 件：crown（顶冠）、frame（框体）、left/right（两翼）、bottom（底饰）、center（轴心）；`assets/sounds/` 是点击水声。

## 已知限制

- **换机器不用改代码**：路径全部"先检索"——先看环境变量（`DSH_HOME` / `QQ_BRIDGE_ROOT` / `QQ_BRIDGE_STATE`），再从包根、工作区、用户目录这些相对位置认门牌（比如 `qq-bridge` 必须带 `state/` 才算）；找不到就返回空、界面上显示"闲着"，**不会去猜某个盘符、也不会在别人家里建目录**。
- 设置项的字体/颜色只作用于**弹窗**，不作用于 DSH 主界面（会话染色是另一块，在「字体美化 → 会话」里单独管）；
- 弹窗靠 DOM 注入 + 启发式选择器，DSH 大改界面结构时可能失效（失效时会在 `~/.dsh/dsh-yushen-popup/diag.jsonl` 留一行诊断）；
- 「后台在忙什么」面板读的是鱼神自己的会话账本（`~/.dsh/dayu/events/`）；没有这个目录的机器上它只显示"闲着"，不影响弹窗本身；
- 只有 HTTP 通道，没有 WebSocket；长轮询每 20 秒断一次重挂，断的那一下不会丢消息（消息在宿主队列里）。
