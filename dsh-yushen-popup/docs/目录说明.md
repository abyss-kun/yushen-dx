# 目录说明（这个插件里什么在哪）

> 换个机器打开一眼能看懂。新增文件先想清楚该放哪一格，放不进去就别加。

## 根目录

| 文件 | 干什么 |
|---|---|
| `index.js` | **宿主半**：配置读写、预览队列、长轮询、事件入口、诊断日志。Node 里跑，不碰界面 |
| `client.js` | **界面半**：画卷弹窗、小黑板、气泡花费、后台面板。浏览器里跑 |
| `package.json` | 名字/版本/入口（`main` + `exports.client`）、DSH 客户端声明 |
| `cordis.patch.yml` | 装进 DSH 时的挂载点（bundle 层） |
| `README.md` | 给人看的：长什么样、怎么用、怎么装 |
| `LICENSE` | AGPL-3.0-or-later |
| `.gitignore` | 忽略本地产物 |

## 目录

| 目录 | 放什么 | 不放什么 |
|---|---|---|
| `lib/` | 宿主侧的小模块：`busy.js`（后台在忙什么）、`paths.js`（路径检索）、`watch.js`（会话账本读取） | 界面代码、素材 |
| `scripts/` | 自检与工具：`selftest.mjs`（零件级 41 项）、`usertest.mjs`（用户视角 10 项）、`check-all.mjs`（一条命令跑两套）、以及抓报错的小工具 | 运行时依赖 |
| `docs/` | 文档（见下） | 代码 |
| `assets/popup/blue|red/` | 画卷素材：crown 顶冠、frame 框体、left/right 两翼、bottom 底饰、center 轴心 | 其他图 |
| `assets/sounds/` | 点击水声 | 语音 |

## docs 里有什么

| 文件 | 什么时候看 |
|---|---|
| `QQ说明.md` | **要发群、要介绍给别人**时看；最后一节可直接复制 |
| `开发流程.md` | 要改这个插件时先看：跑哪两套、怎么算改完（通用流程在鱼神主仓库 `dsh-yushen-twins/docs/开发流程.md`） |
| `弹窗状态.md` | 改弹窗行为前看：五个状态、允许怎么进出、每条不变量 |
| `重载界面-方案.md` | 历史方案，改客户端加载方式时参考 |

## 改东西放哪（速查）

- 改弹窗长什么样 / 按钮怎么走 → `client.js`（顺手更新 `docs/弹窗状态.md`）
- 改配置项、事件接口、日志 → `index.js`
- 加一个自检 → `scripts/selftest.mjs`；加一条用户操作 → `scripts/usertest.mjs`
- 加素材 → `assets/popup/<主题>/`，只放 PNG，命名跟现有一致
- 写文档 → `docs/`，不要堆在根目录
