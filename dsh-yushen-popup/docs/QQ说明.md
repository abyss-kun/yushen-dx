# 发群说明 · dsh-yushen-popup（弹窗）

> 给 QQ 群里的人看的版本。想直接发的话，最后那一段可以直接复制。

## 一句话

DSH 的**画卷式提醒弹窗**。独立插件，纯本地，不调模型，不依赖别的插件。

## 它解决什么

- 有事的时候**弹出来给你看**，不是一条容易被划过去的提示；
- 别的插件、脚本想让 DSH 知道"有事"，调一个接口就行；
- 顺手带的：一个小黑板（手写备忘）、消息边上显示这一轮花了多少钱、开机后能看见谁在跑。

## 长什么样

蓝、红两版画卷。开场两翼并拢，点中间轴心展开；内容多就在框里滚。
关掉有四种：点「好/知道了」、按 **Esc**、点弹窗外面的暗色区域、点「稍后」（这个是推迟，不是关）。

## 怎么装（三步半）

1. 把目录放到你喜欢的位置；
2. `~/.dsh/profiles/desktop/package.json` 的 `dependencies` 里加一行：
   `"dsh-yushen-popup": "link:<你的路径>"`
3. 同一个文件的 `dsh.profile.bundles` 数组里加 `"dsh-yushen-popup"` ← **最容易漏这一步**
4. `pnpm install`，然后重启 DSH。

## 装完先看这几处

- 侧边栏 **✦ 弹窗**：开关都在这里，**改完自动保存、当场生效**，不用找保存键；
- 默认关着的三样：**备份完成提醒 / QQ、B站 来源 / 每轮成本提醒**——
  因为这几样是"我们家自己的东西"（备份、桥、账本格式），别人机器上不一定有，
  所以出厂默认关，要用的人自己去开。

## 和 QQ 怎么配合

QQ 桥（或任何脚本）想让它弹：

```
POST /yushen-popup/event
{ "source": "qq", "badge": "群消息", "title": "有人找你", "body": "……" }
```

- 默认 **关**（`sources.qq = false`）；要用就到后台把「QQ」勾上；
- `source` 换成 `bili` / `local` 是一回事，勾哪个开哪个；
- 推来就弹，不用刷新页面。

## 常见问题

- **装了没反应**：十有八九是 `bundles` 没登记（路由 404、侧边栏没图标）；
- **改设置没变化**：现在改完 0.5 秒自动保存并当场生效；老版本才需要按保存、再等半分钟；
- **换机器**：路径是**自己找**的（环境变量 → 旁边认门牌 → 找不到就显示"闲着"），不用改代码，也不会在你家乱建目录；
- **弹窗关不掉**：点确认键 / Esc / 点外面暗色区都能关；如果后台开了「关闭后保留悬浮窗」，确认键是把它**收成角落里的小画卷**，不是没关。
