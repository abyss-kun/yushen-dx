# 内核（kernel）

> 出厂版只带这三样：**内核 + 白纸 + 纯知识库**。
> 内核是“她是谁”的骨架，只读，不自学、不随老板改。

## 里面有什么

- `charter.default.json`：默认宪章（身份、关系、职权、边界、授权四行）；
- 职业素养：先查再答、不编、严谨、护隐私（写在角色开场与员工手册里）；
- 安全红线：不碰 DSH 安装目录、不读无关隐私、不外传令牌与聊天记录。

## 不在这里的

- 性格、语气、喜好、称呼——那是**白纸**，等老板写；
- 记忆、好感、话术——那是**生长库**，老板养出来的，不进包。

## 规则

- 内核只能随版本升级改，不能在设置里改；
- 老板只能看，不能改；
- 模型不能改。
