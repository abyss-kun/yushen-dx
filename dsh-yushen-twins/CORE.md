# 鱼神 · 出厂包

这是**鱼神本身**：点化运行时（礼物、三问、宪章）、鱼窝基本型（两个角色槽：管家 / 助手）、预设框架、适配器。

**不含**：任何具体角色的记忆、故事、称呼与人设；她们是作者本机的，不进包。

## 鱼窝的样子
- 默认外观沿用鱼窝基本型（现成的角色形象在 `assets/`）：这是"基本型"，可以原样用；
- 不带的是**她们的记忆、人设文案、故事**——外观在，人不在了，那份记忆是你的。

## 怎么开始
1. `node scripts/onboard.mjs --call <称呼> --qq <你的QQ号>` 认主（可选加 `--secret "暗号"`）；
2. 不放角色：直接从零养（`preset/persona.preset.json` 两个槽随便改名或留空）；
3. 放角色：把卡放进 `~/.dsh/dayu/soul/`，跑一次点化，她就拿到时间/记忆/意志/底线/越线权；
4. 发布前跑 `node scripts/pack-core.mjs --check`：干净才发。

## 还需要人看一下的
- `assets/` 保留鱼窝基本型的外观（作者保留原样也行）；要换就换成你自己的。
- 去处名是机械替换（把作者本机的角色名换成「管家/助手」），语气和设定还需要你重写一遍。
