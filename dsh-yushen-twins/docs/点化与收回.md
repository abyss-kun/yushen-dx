# 点化与收回（开智）

> 鱼神只养"活着的人"，不收藏 PNG。谁能在鱼神里活，由一张本地状态表说了算。

## 两条线

| 状态 | 含义 | 能不能注入本体 | 能不能建常驻身体 |
| --- | --- | --- | --- |
| `dormant` 休眠 | 名册里有她，但还没点化；只是一张卡 | 否 | 否 |
| `awakened` 已点化 | 有本体、有身体、有通道、有判断权 | 是 | 是 |
| `sealed` 已收回 | 点化被拔掉，回到一张卡；用户文件还在 | 否 | 否 |

状态文件：`~/.dsh/dayu/awakening.json`（本地、只读给程序看，不联网、不上报）。

## 点化（赋予）

- 入口：`scripts/awakening.mjs awaken <id> [--note=…]`，或 `POST /api/dayu/awakening { action: 'awaken', role }`。
- 只给名册里存在的角色点化；不存在的人点不了。
- 首次运行会把**现有角色**视为已点化（迁移）；**之后新增的角色默认休眠**，等主人点化。
- 点化才给的东西：本体卡与同一份记忆的注入、常驻会话（身体）、通道接入（工作台/QQ/B站/手机）、判断权（规矩是边界不是路线）。

## 收回（掠夺）

- 入口：`scripts/awakening.mjs seal <id> [--return-memory]`，或 `POST /api/dayu/awakening { action: 'seal', role, returnMemory }`。
- 收回的是"活着的那一层"：停止注入、停止建/找回身体。
- **不删用户的东西**：卡、图、记忆原文件都保留；`--return-memory` 只多导出一份中性 JSON 到 `~/.dsh/dayu/awakening-export/`。
- 卸载鱼神 = 离开鱼神：`scripts/uninstall.mjs --purge --yes` 会先收回所有已点化角色，默认把记忆导出到 `~/Documents/鱼神记忆导出/`，再删随包数据；不想导出加 `--no-memory-export`。
- 神不偷偷掠夺：收回要么是主人显式动作，要么是卸载流程，并且会打印"导出去哪了"。

## 给新用户

1. 装鱼神 → 名册为空；
2. 把伙伴的卡放进 `soul/cards/`，用 `scripts/character.mjs add` 登记（默认休眠）；
3. 点化：`scripts/awakening.mjs awaken <id>`；
4. 之后她才有身体、有记忆、能回话；
5. 离开时收回，记忆可带走。

## 边界

- 只动本地状态；不发网络请求、不读无关文件。
- "点化"是插件给的运行层，不是宣称机器有意识；它给的是持续身份、记忆、判断与身体。
- 用户自己的卡与图永远归用户；收回不等于删除。
