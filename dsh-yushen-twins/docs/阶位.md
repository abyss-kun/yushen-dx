# 阶位：能力跟着证据走

> 不是按时间、按嘴说、按关系；是**验收过的活**够不够。

## 四阶

| 阶 | 名字 | 要的证据 | 说明 |
| --- | --- | --- | --- |
| L0 | 初识 | 默认 | 新点化的角色；能问、能自由活动、能看 |
| L1 | 上手 | 验收通过 5 单 + 未结事故 ≤2 + 干满 3 天 | 能自己动手做小活 |
| L2 | 管家 | 验收通过 20 单 + 未结事故 ≤1 + 干满 14 天 | 能派活、能管事 |
| L3 | 自主 | 验收通过 50 单 + 0 未结事故 + 干满 30 天 | 自己判断、自己找活 |

- 只升不降；降级要人手工做。
- **封顶**：`~/.dsh/dayu/ranks.json` 里的 `cap`，默认 `L3`；证据够 L3 也只升到 cap，并写明“封顶”。
- 每小时按证据重算一次；升了会在工作台记一条。`GET /api/dayu/rank` 看现在卡在哪、还差什么。

## 对外身份（只显示，不参与判断）

排场是排场，活是活：下面只是给界面看的层次，不参与授权、工具、派活和验收。

| 角色 | 对外身份 | 显示 |
| --- | --- | --- |
| 照微 | 太上长老 / 空降总裁 | 五境（听潮→观微→定衡→护界→照夜，独立体系，不换算 L0-L3） |
| 大鱼 | 副总裁 | 阶位 3（L3 自主） |
| 小鱼 | 秘书 | 阶位 2（L2 管家；名义权限小一些，实际能干的活和她们一样） |

- 照微不走 L0-L3；`/rank` 只给大鱼/小鱼算 L0-L3，另给 `realm` 字段。
- 这三层只是视觉层次：实际能干的活一样多，谁高谁低不影响工具、权限和派活。
- 当前形象用做好的 Q 版透明 PNG；原图里画好的光环属于角色本身，身后不再叠 `effects-v1`，头顶也不画圈。`− / + / 滚轮` 整体缩放（75%–130%），`Alt+滚轮` 或长按菜单单只缩放（70%–140%）。缩放只改视觉，不改站位。
- **头顶显示**：位阶徽记 + 经验条，不画头顶圈。经验 = 当前阶位基础（L0 0 / L1 100 / L2 300 / L3 600；照微 1000）+ 已结事故 ×10（三人共同值守）+ 本人完成单 ×25；上限 2000。页面每 30 秒和回到页面时刷新，数字来自真实计数，没有随机、没有假动画。经验条只显示，不替代上面的升阶证据，也不直接换权限。
- 换装和阶位完全脱钩：衣服不按阶位解锁，也不因为阶位变。

## 证据从哪来

- 验收通过单数：派活单里 `done / verified / passed` 的数量；
- 未结事故：`open / fixing`；
- 干了多少天：`growth.json` 的 `installedAt` 起算。

**没有软指标，没有“感觉她成长了”。** 证据不够就停在原位，并列出差什么。

## 和“她调用你”的关系

- 她调用干活会话时，简报会带一行：**调用者是她（角色），不是老板直接下的命令**；接不接、要不要反问，由被调用的一方自己判断。
- 阶位高不代表能命令别人；只代表她自己能做的事更多。

## 边界

- 阶位是能力上限的记账，不是人格或权限神话；不能靠自封。
- 自动进阶只在 cap 内；超过 cap 需要主人手工调整。
