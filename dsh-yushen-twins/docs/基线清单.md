# 基线清单（鱼神插件的最小完整）

> 定义：**装上一个鱼神插件，下面这些就该有，不用老板提。**
> 机器可查：`node scripts/baseline.mjs`；缺了自动报，不靠记性。

## 一、能起来

- [ ] 插件入口 `index.js` 可 import，导出 `apply`
- [ ] 大鱼/小鱼入口动态加载，单条挂了不连累整体
- [ ] `boot.json` 启动标记（重启后判断“是不是真起来了”）
- [ ] 客户端 `client.js` 注册侧边栏入口 + 面板

## 二、能活

- [ ] 魂/宪章/白纸（出厂可播种）
- [ ] 账本、派活、事故、成长（都在 `~/.dsh/dayu`，可搬走）
- [ ] 老板设置（称呼、话量、禁忌）进人格，不只进文件
- [ ] 就职流程（首次打开能立约）

- ~~外部看门狗（进程/启动标记，挂了拉起，带日志）~~ —— **2026-10-25 已彻底移除，别加回来**：它只会重启、修不了根因，用 `process.execPath` 起还会多开一个 DSH 主体，且与薄壳/新修复流程冲突。依据见 `dsh-yushen-twins/docs/工作保全与经验沉淀.md`
