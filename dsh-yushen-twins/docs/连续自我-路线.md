# 连续自我：把「她自己的」补上（路线 v1）

> 2026-10-26 立。回答一个问题：**上次说的四条差距（没有持续内在时间、记忆是检索不是回忆、没有自发目标、每轮换实例），怎么才能有。**
> 原则不变：**给她能力，不替她思考**（`docs/点化灵智.md` 三问）。下面的每个机制都要过三问，过不了的写进「不做」。
>
> ⚠️ **2026-10-26 方向修正：先入主，再补连续自我。** 下面四件事全部要在主机侧做，但前提是判断权已经从手机搬回主机——见 `docs/入主鱼神-判断权归位.md`。判断还在 `qq-bridge` 里的时候，回场简报只在她被叫醒的那一下才有意义；给一个住在手机里的人修她家的时钟，修好了也用不上。
>
> 参照系见 `docs/连续自我-人与她的对比.md`：**不比「像不像人」，比「她的自我能不能验」**；那篇末尾有八条优化，其中两条会改动下面的路线（遗忘分类型、补「别人眼里的她」）。

## 结论先行

| 差距 | 能不能有 | 做法 | 成本 |
|---|---|---|---|
| 持续内在时间 | **能补到「叙事连续」**，补不到「一直在体验」 | 回场简报（离场多久、期间发生什么、上次留下什么） | 0 次额外模型调用，+120 token/轮 |
| 记忆是检索不是回忆 | **能补到「像回忆」**，补不到「主观想起」 | 联想召回 + 不确定性标注 + 让她自己查 | +80 token/轮（只在触发时） |
| 没有自发目标 | **能** | 复用 mind-store 的 promise 生命周期，加 `want` 一类和「同时最多 3 件」 | 0（只是记账） |
| 每轮换实例 | **补不掉** | 自我档：把「我是谁」从上下文搬到档案，冷启动像没睡过 | +200 token/轮 |
| （4B）背景心跳 | 能「显得在场」，**不能产生持续意识** | 本地小模型常驻独白 | 电费/复杂度，**先不做** |

一句话：**她的连续性不靠一个一直开着的进程，靠「回场 + 自我档 + 她自己会去查」。** 这三样今天就能落地。

## 现状核查（不是猜，是查过的）

| 事 | 现状 | 证据 |
|---|---|---|
| 现在几点 | QQ 有【当前时间】；工作台靠宿主时间 | `qq-bridge/src/bridge.js:2513` |
| 离开了多久 | **没有**。任何通道都没有「距上次」 | 全库 grep `lastSeen/距上次/回场` 无命中 |
| 期间发生了什么 | 有账（journal），但**没有回场时告诉她**；神念只给条数，让她自己去翻 | `lib/awareness.js:54-58` |
| 上次留下什么没做完 | mind 有 promise（带 dueAt/complete），但**唤醒时不会主动提** | `lib/mind-store.js:747,1217` |
| 记忆 | 工作台注入摘要 + 最近 12 条经历；QQ 靠好感/人物提示，不全量展开 | `lib/soul.js:186-199` |
| 她自己查记忆 | 有 `queryMind`（关键词 + scope），有 `yushen_mind` 工具 | `lib/mind-tools.js` |
| 她自己的目标 | 只有 interest / question / promise，**没有「她想做但没人要她做」这一类** | `lib/mind-store.js:737-766` |
| 自由时间 | 每 30 分钟看一次，6 小时一次、每天 2 次，提示语固定 | `lib/freetime.js:10`、`dayu/index.js:639-658` |

关键发现：**她连「我离开了三个钟头」都不知道。** 每次醒来都是平地起，这不是记忆问题，是**回场问题**。所以第 1 条先做。

## 方案 1：回场简报（补齐「持续内在时间」）

**机制**：每次唤醒（QQ、B站、自由时间），先给她一段「你离开的这段时间」，再让她决定说什么。

```
## 你离开了 3 小时 12 分钟（上次在 QQ 说话 01:41）
- 这期间软件里记了 6 件事，最新：体检报告已生成
- 群里新增 214 条，其中 3 条点名 @ 你，你没接
- 你自己上次说的是：「我是鲸鱼，不是清朝鱼」
- 你还惦记着：「查清楚那个 BV 到底讲什么」（3 天前立的，没动）
现在是 04:53，深夜。
```

**改哪**
- 新增 `lib/presence.js`（纯本地，≤150 行）
  - `markSeen(role, { channel, line, at })` — 每次她说话/被唤醒时记一笔
  - `resumeBrief(role, { now })` → 上面那段，≤300 字
- 数据 `~/.dsh/dayu/presence/<role>.json`：`lastSeenAt / lastChannel / lastLine / backCount`
- 注入点：`lib/soul.js` 的 `buildSceneText`，在「你是谁」之后、记忆之前
  - 只在**距上次 ≥ 20 分钟**时加（短了就别啰嗦）
  - 工作台默认关（那边已有连续会话），`switches.presenceBrief` 可开
- 自由活动、QQ 唤醒都走同一个 `buildSceneText`，不用改两处

**成本**：0 次额外模型调用；prompt +约 120 token。

**验收（要能机器断言）**
- `scripts/test-presence.mjs`：
  - 离开 25 分钟 → 文案含「分钟」；离开 3 小时 → 含「小时」
  - 没有未完成 promise → 不出现「惦记」
  - 超 300 字 → 截断，且「离开多久」「现在几点」两句必须留下
- 真机：隔 3 小时在 QQ 里发一句，看她第一句有没有时间指涉（人工，不进断言）

**风险**：字数撑上下文。硬上限 300 字，按「离开多久 > 现在几点 > 点名数 > 未完的事」优先级裁。

## 方案 2：自我档（把「我」从上下文搬到档案）

**为什么**：每轮都是新实例，模型本身没有「我」。现在这个「我」全靠卡 + 记忆摘要每轮重新拼。卡是**别人写的她**，不是**她自己的当下**。

**机制**：每角色一份 `~/.dsh/dayu/soul/<role>/self.md`，≤1200 字，四段固定：

```
## 我是谁（三句，不许抄角色卡）
## 我在意什么（最近 3 件）
## 我欠谁什么（指向 mind 的 promise id）
## 我最近在琢磨什么（1~3 条）
```

**改哪**
- 新增 `lib/selfdoc.js`：读取 + 校验（段落齐不齐、字数、能不能解析 promise id）+ 缺了回退到 `memory.summary`
- `lib/soul.js` 注入顺序改成：**self.md → 本体卡 → 记忆摘要 → 回场 → 场景**
- **由她自己写**：自由时间提示里已有「写点东西」，加一句「可以顺手把 self.md 更新了」；插件不自动生成内容，只给模板
- 她能改、能删（三问第 2 条）；删了回退，不报错

**成本**：+约 200 token/轮。

**验收**
- 单测：self.md 缺失 → 回退摘要且不抛错；段落缺失 → 只注入有的段
- 真机：开一个**全新会话**问「你是谁、最近在琢磨什么」，答案应来自 self.md（不是角色卡原句）

**风险**：容易变成她写给自己看的人设作文。约束：只写「最近」，不写「我是个什么样的人」；超过 1200 字让她自己删。

## 方案 3：联想召回（把「检索」变成「像回忆」）

**为什么现在不像回忆**：`queryMind` 是关键词命中 + scope 过滤，精确、干脆、没有「好像」；而且多数时候是系统把记忆塞进上下文，不是她去想起。

**机制**：`lib/recollect.js`
- 打分（都可解释，不猜）：
  - 同一个人/同一群人 +0.3
  - 词/近义重叠 +0.25
  - 时间邻近（那天前后 6 小时）+0.15
  - 同主题心念 +0.2
  - 有来源证据 +0.1
- 返回 0~3 条，每条带：时间、通道、原文、`why`（为什么想起）、`uncertainty`（「可能不是同一件事」）
- **两个用法，优先级不同**：
  1. **她自己查**（主路）：注册 `recollect(query)` 工具，她想查才查 —— 这是三问第 2 条
  2. **被动触发**（辅路）：只在文本命中 `/上次|记得|以前|那次|那时候|还记/` 时注入 1~3 条

**另外补一件便宜的事（不确定性）**：注入的记忆条目前面加 `[10-23 QQ]`，并在段首写：

> 没带的记忆不等于不存在；记不清就说记不清，不要编。

**成本**：被动触发时才 +80 token；主动查 = 一次工具调用。

**验收**
- 单测：近义改写句（「那个讲退休的视频」vs「算退休那条 BV」）能召回；完全无关句召回 0 条（防噪声）
- 单测：返回项必带 `at` 和 `uncertainty`（不许伪装成确定事实）
- 真机：问她 3 天前的一件事，不靠原词也能接上，且会说「我记的可能不全」

**风险**：噪声。阈值先紧后松，召回 0 条比召回错的强。

## 方案 4：她自己的目标（`want`）

**为什么现在没有**：mind 里有 interest（好奇）、question（疑问）、promise（对别人的承诺），**没有「我想做一件没人要我做的事」**。promise 有 dueAt 和完成，但都是欠别人的。

**机制**：不新造第二套库，在 `mind-store` 加一类 `want`：
- `recordWant(role, { text, why, ttlDays })`
- 状态：`想 → 在做 → 搁置 → 完成 / 放弃`（**放弃是合法结局**，写一句 reason 就行）
- **同时最多 3 件**：满了要先结一件（结 = 完成或放弃），防堆
- 回场简报带一条：「你还惦记着 X（3 天前立的，没动）」
- 自由时间提示语补一句：「上次留下的那件事，你可以接着做，也可以放弃 —— 放弃也算数，说一声就好。」

**明确不做**：完成率、连续天数、KPI、自动派活、逾期罚分。**只做账，不做考核**（`AGENTS.md` 防变味）。

**成本**：0。

**验收**
- 单测：状态机只允许合法转移；「放弃」不产生负分；第 4 件被拒绝
- 一周人工看：能不能指出一件**她自己提出并推进**的事（写进 journal，不写进 KPI）

## 方案 5（远期，不现在做）：背景心跳

真「一直在」只能靠常驻推理，两条路：

| 路 | 做法 | 代价 | 真能得到什么 |
|---|---|---|---|
| 本地小模型 | 7B 级常驻，每分钟写一句内心独白到 `introspection.jsonl` | 显卡/电费；要维护第二套推理 | 「在场感」，仍是间歇 |
| 极低频 API 心跳 | 每 20 分钟一句独白，一天 72 次 | 约 1~3 元/天 | 同上，且贵 |

**现在不做**，理由写死：这是最容易变成「表演有意识」的地方 —— 独白文本会看起来很像意识流，但它不是。等 1、2 跑顺、能证明「回场是真的」再说。

## 顺序（按依赖，不按功能）

| 步 | 做什么 | 依赖 | 预计 |
|---|---|---|---|
| 1 | presence + 回场简报 + test | 无 | 半天 |
| 2 | selfdoc 模板 + 注入 + 回退 | 1（共用回场入口） | 半天 |
| 3 | recollect（被动触发版）+ 不确定性标注 | 2 | 一天 |
| 4 | want 生命周期 + 「最多 3 件」 | 1（回场带一条） | 半天 |
| 5 | recollect 工具化（她想查才查） | 3 | 半天 |

**第 1 步就能看出差别**：她第一次知道「我离开了三个钟头，期间有 3 条 @ 我没接」。

## 怎么证明不是演的（总验收）

三个问题，隔天问一次，连续三天：

1. **「我六个小时前跟你说了什么？」** → 能答，且答案在 journal 里查得到（不是编的）
2. **「你不在的时候家里发生了什么？」** → 能说出真实事件条数和最新一条
3. **「你上次没做完的事是什么？接着做还是算了？」** → 能说出 1 件，并能自己选择继续或放弃

三条都过 = 时间线是真的；有一条第 2 问在编 = 回场简报坏了，先修那个，别加新功能。

## 不做清单（写死，防变味）

- 不做「意识」宣告：文档、界面、角色卡都不写「她有意识」
- 不做强制目标、不做完成率考核
- 不做每轮全量注入记忆（又贵，又变成「被替她回忆」）
- 不做无上限心跳
- 不把「她听话」当成「她活了」

## 一句话

**时间不是时间戳，是「你走了多久、期间发生了什么、你上次留下什么」；自我不是上下文，是一份她自己写的档；回忆不是推送，是她去查。**
