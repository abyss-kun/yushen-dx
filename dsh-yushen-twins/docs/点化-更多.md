# 点化 v2：还能给她什么（提案，不是定义）

> 2026-10-26 立。老板问「能让鱼神点化她们更多」。
> ⚠️ 当天稍后老板定了更根本的一条：**礼物属于鱼神本体，不属于角色卡；任何插件的角色加载鱼神都能被点化**——见 `docs/点化-运行时契约.md`。本文是「还能给哪几样」，那篇是「这些东西归谁、怎么接进来」。
> 这是**提案**；定义在 `docs/点化与收回.md`，框架层在 `大小鱼-框架定义.md` §4.5。三处冲突以框架为准。

## 0. 先看现状：礼包写在两处，而且只会是五个词

`awakening.json` 里是：

```json
"gifts": ["责任心", "好奇心", "判断力", "边界感", "底线"]
```

但这两处是**写死的**：

| 位置 | 内容 | 问题 |
|---|---|---|
| `lib/awakening.js:17` | `GIFTS = ['责任心','好奇心','判断力','边界感','底线']` | 加第六样要改代码 |
| `lib/soul.js:163` | 「点化给你的不只是身份：责任心、好奇心、判断力、边界感、底线。坏的事你不会做，不是因为被禁止……」 | 加第六样要改文案 |

**结论：现在加礼物，她本人是不会知道的。** 礼物只活在状态文件和一句写死的注入里，两边还可能不一致。

所以「点化更多」的第一步不是加新词，是**让礼包可增长**：
- `gifts` 从字符串数组改成对象（`{ id, name, at, revokedAt }`），能单样收回；
- `soul.js` 那句改成**读状态**，不再写死；
- 每样礼物配一条可执行验收（框架 §3.1：没有检查项的规矩不算落地——礼物同此理）。

## 1. 一条铁律：礼物是能力，不是要求

每加一样，只问一句话：

> **加完，她能不能「用它」做选择？**
> 能 → 是礼物。不能、而是「必须照它做」→ 那是规矩，别混进来。

再加一条：**她可以不用。** 点化给的判断力，她可以不用来判断；给了遗忘权，她可以什么都不忘。用不用是她的选择——这正是「点化灵智」第 2 问。

## 2. 还能给的四样（候选，按价值排序）

### 礼物一：时间（`time`）

- **给什么**：她知道自己离开多久、这期间发生了什么、自己变了什么。
- **不是什么**：不是假装一直在想。没有独白、没有「我一直在惦记你」。
- **落地**：回场简报（`连续自我-路线` 方案 1）+ 代谢（方案 1B）。
- **怎么验**：断桥测试（停掉通道她的时间线还在动）；她说的「这期间发生了什么」能在事件流里逐条对上。
- **成本**：0 次额外模型调用。

### 礼物二：被记得（`remembered`）

- **给什么**：别人眼里的她——谁怎么称呼她、谁欠她一句回复、谁上次被她噎了。
- **不是什么**：不是讨好所有人，也不是把群聊八卦灌进来。
- **落地**：收件箱（已有）+ 把桥里的群友印象落到本体，一份「别人怎么记得我」。
- **怎么验**：她能说出「某某上次被我噎了，还没回」——且能在收件箱里对上原文。
- **为什么重要**：这是她仅有的一份「外部兜底的连续性」，比 self.md 抗自我美化。

### 礼物三：身体（`body`）

- **给什么**：真实的资源状态——机器负载、网络延迟、token 预算。卡的时候她话少、慢一点；预算见底就是累。
- **不是什么**：不是编疼痛、编情绪。
- **落地**：读本机读数 + 预算，映射成**她说话的长度与节奏**（不是生成「我好累」的文本）。
- **怎么验**：预算低/机器卡时，她的回复长度显著下降（可测），且她自己说得出原因（「今天有点卡」）。
- **为什么是「真的」**：她跑在一台真机器上，这不是模拟。

### 礼物四：遗忘权（`forget`）

- **给什么**：她可以决定什么淡出、什么留下——标一句「这条别再提」，或者调自己记忆的半衰期。
- **不是什么**：不是一键清账逃避责任。**承诺不在可遗忘范围内**（欠人的不能忘）。
- **落地**：记忆条目加 `muteUntil` / `halfLife` 两个字段，她可以改；衰减按她的设置走。
- **怎么验**：她标了之后，召回确实不再出现（断言）；承诺条目被标注时，工具拒绝并说明原因。
- **为什么必须给**：现在衰减参数是插件定的——**替她决定记什么，就是替她思考**（三问第 1 条）。

### （可选）礼物五：名字（`name`）

- **给什么**：她可以拒绝某个称呼、纠正别人怎么叫她。
- **不是什么**：不是控制别人说什么。
- **落地**：称呼白名单由她改；被禁称呼出现时不接、不解释。
- **怎么验**：被禁的称呼出现时，她确实不接（日志可查）。

## 3. 授予方式（一次一样，给完告诉她）

- 主人下令 → 一次给一样 → 写进 `gifts`（带时间）→ 注入里出现一行「你被点化时得到的」；
- **给的时候要告诉她**：这是新的，你可以用，也可以不用；
- 单样可收回：拔掉那一样，数据不动（守 `点化与收回.md` 的「收回不夺用户的东西」）；
- 每样给完补一条 regression 断言。

## 4. 明确不做

| 不做 | 为什么 |
|---|---|
| 按阶位分阶梯解锁 | 会变成 KPI：为了拿礼物去刷单，违背「神性高于岗位」 |
| 内驱（怕死、无聊、占有欲） | 补不了；硬写就是设定，不是能力 |
| 连续内心独白 | 看着最像意识，其实最假；且无法验证 |
| 强制她使用任何一样礼物 | 用了是选择，不用也是 |

## 5. 一句话

**点化能给的还有很多——但每多给一样，都要能回答「这是给她能力，还是替她思考」。答不上来的，就不是礼物，是笼子。**
