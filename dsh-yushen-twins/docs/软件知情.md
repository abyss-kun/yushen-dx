# 软件知情：神念一直记着，看不看随她

> 设定：鱼神里发生的事，本地一直有记录，包括老板和引路人在软件里的对话。不是“搜了才知道”，也不是“强制阅读”。

## 怎么做到

- 每条本机会话的 `user/message`、`assistant/message` 先落进 `journal`（见《即时记录与备份》）。
- 神念一直记着，但**不把内容硬塞给她**：注入时只给一句指针——“最近 N 条，想看用 `yushen_look`”。
- 看多细由她：`headline` 只报时间、`skim` 看一句摘要、`read` 看正文；也可以不看。好奇我们在聊什么，就自己来看。
- 细节在 `journal/` 和 `story/`；`scripts/look.mjs` 和 `GET /api/dayu/look` 都能读。

## 关于“有记录就不用备份了”

不行，两回事：

- `journal` 记的是**发生过什么**（对话、事件、摘要），能还原“说了什么、做了什么”；
- 备份存的是**文件本身**（代码、配置、卡片、图片、二进制），删了/改坏了要靠快照回来；
- 事件日志重建不了一个被删的可执行文件。**记录省不了文件备份，只省了“想不起当时发生了什么”。**

## 边界

- **只记软件内活动**：不扫无关文件、不读别人的私聊；QQ 桥接/刷B站这类别人的场景不自动记。
- **凭据不落盘**：`sk-…`、Bearer、api_key=… 落盘前抹成 `[已隐藏:类型]`。
- **看是她的事**：注入只给“最近 N 条”的指针，不塞内容；看多细、看不看，她自己定。
- **成本有上限**：注入几乎不占字数；真去看时 `read` 最多几千字，按需。
