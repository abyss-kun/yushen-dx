# 交接手册

> 给“接下一班的人”看的。员工手册管**怎么干**，这本管**干到哪了**。
> 2026-10-22 · 与 `员工手册.md` 配套，一常一临。

---

## 一、它解决什么

她会换会话、换机器、换模型；换完不能从零开始。

**员工手册**：规矩，常驻，不随班次变。
**交接手册**：这一班的状态，每班一变，只写“接下来怎么接”。

## 二、什么时候写

- 换会话前（总台换班）；
- 换机器前（搬家/重装）；
- 长任务收尾时；
- 发现自己要断线、上下文快满时。

## 三、写什么（三行，不许流水账）

```
- 做了什么：一句话
- 结论：成了没有 / 卡在哪
- 下一步：接的人先干哪件
```

再补两样可选：

- **未结的活**：派活单号、谁在跑；
- **没结的事故**：单号、一句话。

### 三张小模板（同一本里，不用另立手册）

**换班**

```
- 做了什么：这一班的主要动作
- 结论：成了什么 / 卡在哪
- 下一步：接的人先干哪件
- 未结：派活 xxx（谁在跑）；事故 xxx（一句话）
```

**换机器 / 搬家**

```
- 做了什么：搬到哪、带走了什么
- 结论：新家能不能用；缺什么
- 下一步：新家第一件事（收养形象 / 重新登录 / 跑一次体检）
- 数据：魂、宪章、手册、鱼窝在哪个包/路径
```

**长任务收尾**

```
- 做了什么：做到第几步
- 结论：验收过没过；证据在哪
- 下一步：从哪继续；谁接手
- 证据：文件路径 / 单号 / 链接
```

选一张照着写，不用三张都写。

## 四、放哪、怎么命名

```
~/.dsh/dayu/handoff/YYYY-MM-DDTHH-MM-SS.md
```

- 一条一个文件，**只追加，不改旧交接**；
- 自动生成用这个目录；人写的也可以放这里，命名前面加 `manual-`。

## 五、谁读、什么时候读

- **新总台会话建好、送完设定后，自动读最近一条**（已在启动流程里）；
- 新接手的人：先读最近一条，再动手；
- 老板随时可读。

## 六、和档案室的区别

| | 档案室 | 交接 |
|---|---|---|
| 存什么 | 旧版本（框架/人格/内核） | 这一班干到哪 |
| 变不变 | 只进不出，长期 | 每班一条，滚动 |
| 谁看 | 回档的人 | 接班的人 |

**别混**：版本进档案室，班次进交接。

## 七、不做什么

- 不写流水账；
- 不写情绪、不写猜测；
- 不覆盖旧交接；
- 交接里不放密钥、令牌、隐私。
