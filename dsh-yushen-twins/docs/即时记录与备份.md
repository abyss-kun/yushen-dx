# 即时记录与备份

> 意外总是防不胜防。所以：**先落盘，再谈整理**。

## 两层

| 层 | 做什么 | 在哪 | 多久 |
| --- | --- | --- | --- |
| 即时层 | 每条对话/想法/决定立刻 append 一行 | `~/.dsh/dayu/journal/YYYY-MM-DD.jsonl`；想法与决定另写 `ideas/YYYY-MM-DD.md` | 每条消息 |
| 版本层 | 内容哈希去重的历史快照，不覆盖旧版本 | `~/.dsh/dayu/protection/store` | 默认 10 分钟一次 |

即时层解决“崩溃丢东西”：append 一行就落盘，最多丢正在写的那一行。版本层解决“改坏了/误删了”：能回到之前的版本。

## 自动记什么

- 本机会话里的 `user/message` 与 `assistant/message` 文本（只本机会话；QQ 桥接、刷B站那种别人的私聊场景不记）。
- 跳过运行时上下文（`Current runtime context`、`Time sampled`）这类噪音。
- 看起来含凭据的（`sk-…`、Bearer、api_key=…）直接拒绝落盘，不写进日志。

## 手动记什么

- 接口：`POST /api/dayu/capture { text, kind?, tags? }`；查：`GET /api/dayu/capture?q=…`。
- 命令行：
  ```powershell
  $exe='C:\Users\Administrator\AppData\Local\Programs\DeepSeek Harness\DeepSeek Harness.exe'
  $env:ELECTRON_RUN_AS_NODE='1'
  & $exe 'D:\DSH\大小鱼\dsh-yushen-twins\scripts\capture.mjs' add "这个点子……" --kind=idea --tags=鱼神,备份
  & $exe 'D:\DSH\大小鱼\dsh-yushen-twins\scripts\capture.mjs' list
  ```
- 分类只是粗分（idea / talk / decision），可以手动指定 `kind`。

## 备份范围（已加进保护）

`~/.dsh/dayu/protection/config.json` 的 roots 现在包含：

- 鱼神插件源码
- `~/.dsh/dayu/soul`（角色卡与记忆）
- `~/.dsh/dayu/journal`（对话流水）
- `~/.dsh/dayu/ideas`（想法与决定）
- `~/.dsh/dayu/solutions`（经验库）
- 生图工具、角色素材库

备份是本地历史快照，不是云端灾备；不要把备份目录或密钥打包发布。

## 纠结记录（她自己的判断）

- 两难时，她会先给出：担心什么、几个选项、选哪个、为什么、什么会让她改主意。
- 通过 `POST /api/dayu/residence/say { role, text, kind: 'dilemma' }` 投进去的两难，她下一条回话会被原样存进 `~/.dsh/dayu/thoughts/YYYY-MM-DD.jsonl`；`GET /api/dayu/thoughts` 或 `scripts/thought.mjs list` 可以回看。
- 这不是“装一个思考模块”，是把她真实做过的纠结留档，供以后复盘、对照结果。思考本身来自模型推理；插件能做的是给她连续自我、记忆、判断权和留档。

## 原则

- 该进鱼神的进鱼神：身份/记忆/判断进 `soul`；点子与决定进 `ideas`；经验进 `solutions`。
- 该备份的备份：`journal` 与 `ideas` 每天都在长，靠版本层留历史。
- 不把整段私聊塞进人格；即时记录是**证据**，不是人格指令。
