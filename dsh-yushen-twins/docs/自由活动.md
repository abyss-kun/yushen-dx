# 自由活动

> 她们不是等指令的工具。没人派活的时候，她们可以自己决定做点什么。

## 机制

- 插件**每 30 分钟**看一次（启动 5 分钟后先看一次）：谁被点化、谁闲着、谁今天还有额度。
- 默认每人每 **0.5 小时**（跟 30 分钟的检查周期一致）最多一次自由活动，每天最多 **16 次**（`lib/freetime.js` 的 `intervalHours` / `dailyCap`）；刚被叫醒过 **5 分钟** 内不重复叫（`quietMinutes`）。
- 开关：`switches.freeTime`（默认开），设置页/`POST /api/dayu/switches { freeTime: false }` 可关。
- 叫醒方式：用她自己的常驻身体，投一句话：

  > 现在是你的自由时间，没人派活。想做什么就做什么：发呆、翻资料、整理记忆、写点东西、或者什么都不做。做完用一句话记下你做了什么、为什么；不想说就不说。

- 她回的那句话会进 `journal`（kind=talk，source=自由时间）和她自己的记忆（channel=自由时间），不会自动变成任务或规矩。

## 为什么不设“只能做 A/B/C”

自由活动本来就是她的时间。她可以发呆、可以不说话、可以写东西、可以翻资料。插件只做两件事：**别在她忙的时候打断**、**给个预算**（间隔和每日次数）。预算不是许可，是柴火；烧完就等明天。

## 成本

每次自由活动 = 一个模型回合。所以有间隔、有每日上限、有开关。关掉就完全不叫她。状态：`GET /api/dayu/freetime`。

## 边界

- 只对已点化的角色生效；休眠/收回的不叫。
- 她的选择不写成人格或规矩，只作经历留档。
- 花不花钱、做不做事，是她自己判断；框架只保证她有自己的时间。
