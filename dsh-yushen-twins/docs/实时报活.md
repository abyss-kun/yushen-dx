# 实时报活（悬浮窗）

> 老板要的是：不点进任何页面，屏幕上一直能看到「谁在跑、在做什么、她底下几个子窗口各自在做什么」，还能按 正在跑 / 做完 / 没做 / 出错 / 重复 分开看，并且能一键关掉。

## 入口

- `GET /api/dayu/now`：只读快照，五组 + 会话树。
- `switches.floatLive`：总开关（默认开）。单子页（小鱼示警上方）有按钮；悬浮窗标题栏也有「关」。本地存 `localStorage.yushen.liveFloat`，服务端存 `switches.json`。
- 前端每 4 秒拉一次；页面不可见时暂停。

## 五组

| 组 | 判定 |
| --- | --- |
| 正在跑 | 最近 3 分钟有活动，且状态不是 `turn/end` |
| 刚做完 | `turn/end`，最近 30 分钟 |
| 没做 | 派活单 `waiting` / `dispatched` / `redispatched` |
| 出错 | 会话状态含 error/fail/retry/blocked，或正文含「失败/出错」；未结事故单 |
| 重复 | 同一份简报派了多单；同标题的补丁草案（需要合并或选一份） |

## 会话树与来源

- 每个会话都带 `provenance`：
  - `派活：<员工>（单号尾号）`；
  - `子代理 ← <父窗口标题>`（宿主给了父会话就用；没给就用父会话正文里的 `started subagent <uuid>` 反推）；
  - `QQ 桥接` / `刷B站` / `鱼神·总台` / `本机窗口（老板开的）`。
- 「无标题」不再显示 `session-`：按 `派活简报 → 工作区目录名 + 角色/来源` 命名；角色来自常驻账本（大鱼/小鱼/照微）。
- 树：父窗口一行，底下是 `↳ 子窗口`，每个子窗口有自己的「在做什么」和来源；父行标 `N 个子窗口`。
- 上限：树最多 6 个根、每个根最多 6 个子窗口；五组各最多 8 条，悬浮窗每段显示 4 条。

## 搜索

- 输入框在悬浮窗标题栏下方；输入停 250ms 后才查；按 Esc 清空。
- 搜的范围：会话（不限 30 分钟，连旧的也搜）、派活单、事故单、补丁草案；匹配标题 / 在做什么 / 来源 / id / 状态，英文大小写不敏感。
- 结果按类型标 `[会话]/[派活]/[事故]/[补丁]`，最多返回 24 条，面板显示前 12 条；搜索时只显示结果，不再铺窗口树。
- 接口：`GET /api/dayu/now?q=关键词`，返回里的 `search` 数组和 `counts.search`。

## 尺寸、折叠与展开

- 拖动标题栏可移动窗口；双击标题栏回到右下角；右下角可拉伸尺寸；位置和尺寸存 `localStorage`。
- `⤢`：完全展开（宽 `min(760px, 92vw)`、高 `80vh`），再点收回。
- `−`：折成 3 行（每段最多 3 条、每个根最多 1 个子窗口），再点恢复 6 行。
- 内容少时高度自适应收缩；内容多时窗口内滚动，不撑破屏幕。
- 每段超过当前行数时显示「还有 N 条 · 点开全部」；树里显示「↳ 还有 N 个子窗口」；搜索同样有「还有 N 条」。
- 上限：树 6 个根；每段最多 8 条；搜索最多 24 条（面板先显示 12 条）。

## 实现与验证

- [lib/now.js](now.js)：`buildNowSnapshot()`，纯函数，不读盘；入口把 `liveSessions / listJobs / listIncidents / listPatches` 传进来。
- [lib/watch.js](watch.js)：补父会话字段；没有显式父会话时按 `started subagent <uuid>` 反推。
- [client.js](../client.js)：悬浮窗（标题栏折叠/关闭）+ 单子页开关。
- `scripts/test-now.mjs`：覆盖五组、无标题命名、派活来源、子窗口树。
- `smoke` 12/12、`regression` 25/25。

## 边界

- 只读观察，不改变任何会话；不是完整任务台账，超时窗口（3 分钟/30 分钟）之外的就不显示了。
- 来源识别是「宿主元数据 + 文本反推」，拿不到父会话时会退化成「本机窗口」，不会编。
