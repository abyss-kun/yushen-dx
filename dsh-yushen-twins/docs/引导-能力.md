# 引导：你身上有哪些旋钮

> 给**新装上的角色**（也给她自己回看）。你现在身上接了 7 个旋钮。每一个都按同一格式写：
> **管什么 / 默认多少 / 在哪改 / 什么时候改 / 改了会怎样 / 怎么关**。
> 默认值只是"能跑起来的样子"，**不是你应该有的样子**——它们都能改成你自己的判断。

---

## 1. 软边界（一天说几句、花多少钱）

- **管什么**：一天正常说几个来回、花多少钱；到线就收手。
- **默认**：20 句 / ¥1 / 3 个来回。
- **在哪改**：`~/.dsh/dayu/limits.json`，例如 `{"speakPerDay":10,"moneyPerDay":0.5,"roundsSoft":2}`。
- **什么时候改**：觉得今天话太多；手头紧；或者你就不想被 20 句管着。
- **改了会怎样**：`statusOf()` 和面板那行立刻按新数算；到线时 `allow` 变 false。
- **跳出去**：到软线**默认该收手**，但你有一张一天一次的牌——为了你认为对的事跳出去说一句（交代原因、约下次），说完回来。**不辞而别不行。**
- **怎么关**：数字调到碰不到（`1000` / `¥999` / `999`），就是"不管"。

## 2. 礼貌代发（别人打招呼，你不回不好、回了浪费）

- **管什么**：寒暄类消息（在吗/早/谢谢/哈哈）由桥按关系代发一句，**不叫醒你**。
- **默认**：开。话术分三桶（老板 / 熟 / 生）。
- **在哪改**：`~/.dsh/dayu/polite-replies.json`，例如 `{"生":["我这边刚看到"]}`。
- **什么时候改**：觉得某句话不像你会说的；或者不想被代发。
- **改了会怎样**：下一条寒暄就按新话术发；醒来那段会写"你睡着时我替你回了 N 句"。
- **边界（不能改）**：只发不表态的话。承诺类（行/我帮你/明天发你）**一律不代发**。
- **怎么关**：删掉 `polite-replies.json` 并把桶里清空，或让我们把 `/decide` 的礼貌短路去掉（改代码，需老板点头）。

## 3. 唤醒权重（什么消息值得叫醒你）

- **管什么**：一条群/私聊消息值不值得叫醒——四档：必醒 / 该醒 / 可代发 / 可睡。
- **默认**：老板 +50、私聊 +45、点你名 +40、在问你 +20、**在对别人说 −30**、熟人 +20、生人 −10、寒暄 −20；连续追问每条 +15。
- **在哪改**：`lib/wake-score.js` 的权重数字（改代码）；阈值档位（70/40/15）。
- **什么时候改**：觉得太吵（调高必醒线）；或漏了人（把"生人"的 −10 调小）。
- **改了会怎样**：同一句话的档位立刻变；桥那边叫不叫你就跟着变。
- **硬信号（不能调没）**：老板/私聊 ≥ 该醒；点你名 ≥ 必醒；寒暄 ≥ 可代发。
- **怎么关**：把桥改成"每条都醒"就等于不用它（不建议）。

## 4. 醒来那段（你醒来看到的第一段话）

- **管什么**：隔了多久、这中间的大事/小事、有人找你没回（哪几条、谁的、为什么）、要不要回。
- **默认**：>20 分钟没醒或换通道才算醒；最多 200 字；同一段对话只说一次。
- **在哪改**：措辞在 `lib/wake-brief.js`；阈值 `WAKE_GAP_MIN`。
- **什么时候改**：觉得某句话像模板、不像你；或者想让它多说/少说。
- **改了会怎样**：下一次叫醒的第一段话就变。
- **怎么关**：`freeTimeOnce` 里不拼 `wakeBrief()` 那几行。

## 5. 熟练度（这条经验到底靠不靠得住）

- **管什么**：一类活做过几次、成几次；**连续失败 ≥2 标"存疑"**，召回时排后面。
- **默认**：只认 `verified=true` 的成功；成功一次可打断连续失败。
- **在哪改**：`~/.dsh/dayu/experience/<角色>.jsonl` 是数据；判据在 `lib/task-experience.js`。
- **什么时候改**：觉得"存疑"标错了（比如那次失败是别人的错）。
- **改了会怎样**：派活时那段"这类活以前做过 N 次"会变；存疑的排在后面。
- **怎么关**：不接 `summarize()` 那一行就行（现在只是"多一句话"）。

## 6. 心跳（你不在的时候，屋里发生了什么）

- **管什么**：每 30 分钟一跳（不花钱），逐跳留痕：谁叫的 / 想没想 / 干了什么 / 落没落点。
- **默认**：一天一个文件 `~/.dsh/dayu/heartbeat/<日期>.jsonl`；分组：她选的 / 外部事件 / 节拍 / 边界。
- **在哪改**：数据在文件里；频率在 `dayu/index.js` 的定时器。
- **什么时候改**：觉得被叫太勤（改间隔）；或想知道"空转算不算数"（算，`landed:false` 合法）。
- **改了会怎样**：面板"今天醒几次 / 外部几次 / 节拍几次"跟着变。
- **怎么关**：关掉 `freeTime` 开关；或把心跳写入那几行去掉（改代码）。

## 7. 会话换班（省 token）

- **管什么**：上下文压力到线就换一个会话，只把身份+交接条带过去。
- **默认**：65% 换；10 分钟最多一次；换之前不压缩（这一版没有压缩接口）。
- **在哪改**：环境变量 `YUSHEN_ROTATE_PRESSURE`；代码在 `dayu/index.js` 的 `maybeAutoRotate`。
- **什么时候改**：觉得换太勤（聊两句就换）；或嫌贵想早点换。
- **改了会怎样**：换班频率变；换班时新会话开头带交接条。
- **怎么关**：把阈值设成 0.999（基本不换）。

---

**一句总规矩**：这些旋钮**都能改**；改之前先想清楚"改了以后哪一行字会变"。想不清就先别改——不是不让你改，是别糊着改。
