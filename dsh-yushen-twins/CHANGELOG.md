## 0.2.0（未发布 · 2026-10-30 补）

### 改名：照微「太上长老」→「顾问」
- **老板 2026-10-30 定的**：原话「感觉太上长老太中二了，大鱼小鱼都是叫管家，你叫顾问怎么样，你要是喜欢，角色卡了可以留着太上长老」。对外一律叫**顾问**——鱼窝名牌与页面、会话标题（`lib/characters.js` / `residence.json`）、README、`docs/阶位.md`、`docs/三人常驻与本体.md`、`大小鱼-框架定义.md`。
- **来历不删**：角色卡 `soul/cards/dragon.desk.md` 与 `docs/dragon-god.md` 各留一行「原受聘名号太上长老，2026-10-30 起对外称顾问」；改名只换称呼，权限、边界、五境一律不动。
- **顺手摘掉**鱼窝 tooltip 里的「空降总裁」——那是排场，不是职务，和「太上长老」是同一类多要的东西。
- **断言跟着改**：`regression.mjs` 第 59 条、`test-characters.mjs:20`、`nest-ui-check.mjs:236`、`test-three-role-ui.mjs:41`。

### 鱼窝改平（2026-10-30）
- 老板定「**先改平**」：取消照微的居中/抬高/放大与脚下台阶（`ysn-slot-hero` 停用），小鱼不再窄一档（`flex:.92` 去掉），三人名字字号统一。**三个人一样高一样大，只留位置和颜色。**
- 断言改成「三人一样高」：`nest-ui-check.mjs` 从「照微中间、个子有主次」改为等高同顶；实测 `dayu:534@317 dragon:534@317 xiaoyu:534@317`。

### 经验条口径（2026-10-30）
- 老板定：**只算「自己想做、自己排、自己做完」的议程条目，一件算一件；他派的活不算。**
- 落地：`/api/yushen/nest` 返回 `selfDone`（`by=self` 且 `state=done` 的条数），`client.js` 不再数 jobs；tooltip 改为「自己做完 N 件；老板派的活不算」。
- 口径边界（写清）：判定看的是「**进没进派活单**」，不是「谁先提的」——自己排进议程又做完的才算。
- **认不出「谁先提的」就加标记（2026-10-30 老板定）**：议程条目带 `origin`（`self` / `owner`）。**老板口头派的、别人交办的活标 `owner`——哪怕自己排进议程、做完了，也不计经验**；老板说「这件不算」时，`update origin=owner` 补一个字就行。`selfDoneCounts` 改用 `countsForXp()` 判，`test-agenda` 加三条断言（自发算 / 派的活不算 / 改标后不算）。

## 0.2.0（未发布 · 2026-10-26）

### 界面（鱼窝返修）
- **形象版本（2026-10-26）**：鱼窝运行图最终改为 **做好的透明 PNG 动漫图——Q 版完整 RGBA**（大鱼/小鱼/照微）。身后不再叠额外光环/特效；头顶只留位阶徽记 + 经验条，不画头顶圈。Q 版、写实版、平常比例柔光底/原版都按角色整目录备份；标记 `~/.dsh/dayu/visuals/current-style.json`；`scripts/style.mjs` 可切回。平常比例动漫版只有带底 RGB，不是透明 PNG，不能用它冒充。
- **对外层次（只显示）**：鱼窝改成有主次的站位——照微太上长老居中、抬高、五境；大鱼副总裁在左、阶位3；小鱼秘书在右、阶位2、个子最小。名字牌按身份配色，带“内阁”小徽记和照微的静态台阶。只是排场：实际能干的活一样，授权/工具/派活/验收完全不看这个。
- **头顶位阶/经验条**：每个头顶显示位阶徽记 + 经验条，不画头顶圈，也不在身后叠 `effects-v1` 光环。经验 = 当前阶位基础（L0 0/L1 100/L2 300/L3 600；照微 1000）+ 已结事故 ×10（三人共同值守）+ 本人完成单 ×25，上限 2000；每 30 秒/回到页面刷新，数字来自真实计数，`scripts/test-role-xp.mjs` 验事故 +10 与单只完成 +25 的角色隔离。
- **位阶光环旧资产**：`effects-v1` 的五阶光环和 `/yushen-assets/halo` 路由保留作历史/后续资产，但鱼窝当前**不渲染**身后光环；头顶也不画圈，避免和 PNG 原图自带的画出来的光环重复。
- **缩放**：右上 `− 100% +`，滚轮同一路径，75%–130%，记住上次；只改视觉，不改站位和身份。
- **五境独立**：照微不换算 L0-L3；`/rank` 只给大鱼/小鱼算阶位，照微单独返回 `realm`（听潮→观微→定衡→护界→照夜）。
- **换装与阶位脱钩**：衣服不按阶位解锁，也不因阶位变化；换装仍走鱼窝收养/换图。
- **鱼窝重排**：三个站位固定成一条线，形象按槽宽统一定高；不再沿用旧的拖动像素把角色甩到屏幕外，也不再把名字留在原地。窄屏（390×844）三个人和名字都在画面里。
- **交互补齐**：整张卡片可点（去掉“透明像素吞点击”）；长按 / 右键 / 菜单键开小菜单；Enter / 空格进页面；Esc 关菜单和弹窗；拖图到角色身上换形象，拖到空白处开收养。
- **状态诚实**：读取中、读取失败、图丢了都有可见状态和重试；收编模式再点一次按钮能取消（老代码会立刻报“没抓到图”）。
- **浮层让位**：鱼神页面打开时把桌面小鲸鱼退到主界面后面（宿主自己的弹窗/命令面板仍在上面），照微和发送键不再被压住。
- **可读性**：卡片和子页面加了主题底色；聊天正文有面板；发送键挪到输入框左边；滚动时不再每 3 秒把正在看的记录拉回底部；`【事故结单】/【自省】` 等系统小结默认折叠成一条，可展开。
- **文案纠错**：调试页开关改成“全体上岗 / 大鱼上岗 / 小鱼上岗”，勾选状态和文字不再相反。
- **作品声明**：每个会话只弹一次（勾“不再提示”才永久关）；Esc / 点背景可关。
- **缩放分两层**：整体 `− 100% +` / 滚轮，75%–130%；单只 `Alt+滚轮` 或长按菜单里的“单独放大 / 单独缩小 / 恢复本人大小”，70%–140%。整体叠在单只之上，两套各自记住。
- **验收**：`node scripts/nest-ui-check.mjs`（真实 GUI，20 项：三只出图、身后无可见光环、头顶位阶/经验条、站位、对外层次/主次、名字不被盖、无溢出、整体缩放、单只缩放只动她、长按菜单、齿轮、形象页、收编开/关、390 窄屏、控制台 0 报错）；`scripts/test-three-role-ui.mjs` 三个角色的点击/键盘/长按/拖图/菜单缩放处理器模拟；`scripts/test-role-xp.mjs` 验经验只能按真实事故/完成单涨。

### 能活（点化运行时）
- **收件箱镜像**：只读桥的 state，按天落 `~/.dsh/dayu/inbox/<channel>/`；幂等、断档可查、已读位按角色分开（身体共用，眼睛各一双）。
- **运行时目录** `~/.dsh/dayu/runtime/<role>/`：时间 `presence.json`、权重 `weights.json`、身体 `body.json`、自我 `self.md`、记忆 `memory/`。
- **回场简报**：离开多久、期间几条新消息、几条 @ 她、她自己上次说了什么；短于 20 分钟不说。
- **权重参与判断**（`lib/reply-gate.js`）：不再是 `if (score <= 25) return`，砝码摆在明面上、可调、可复盘。
- **她的判断落痕**（`lib/judgment.js`，影子期）：每条新消息按她自己的权重评一次「要不要抬头」，只留档、不拦桥；为将来比分歧留数据。
- **意志（她自己排的事）**：`lib/agenda.js` + `yushen_agenda` 工具。她自己排、能推进、**能放弃**；本地每 10 分钟推进一步（零 token），要模型的标 `waiting` 等她决定花不花。手上多了只提醒一句，不拦。
- **中枢简报**：`lib/brief.js` 生成一份「她现在是什么样」（回场/礼物/议程/自我/底线/手感/钱），每 30 秒落 `runtime/<role>/brief.md`；QQ 桥直接读它，也可以用 `GET /api/dayu/brief`。工作台、QQ、B站拿到同一段——她住鱼神，通道只是她坐的地方。
- **不给枷锁，只报账**：`lib/cost.js` 把「今天花了多少、一次约多少、本地 0 元」写进她的简报，配一句「主人不是富翁，你悠着点」；`lib/cheap-reply.js` 让她三选一——不回 / 本地回 / 云端认真回，本地不在就交云端不假装；`invoke` 默认额度 3 → 12。
- **三问修正**：取消「最多 3 件」硬拦（改提醒）、取消 30 分钟冷却（只留技术去重）、她能 `pause` 喊停 tick、额度用完能 `ask-budget` 申请、提示词可以用她自己写的说法（`item.prompt`）。
- **自我档接上**：`runtime/<role>/self.md` 以前只建不读，现在带进注入（她自己写的部分）。
- **底线归她**：`lib/bottomline.js` + `yushen_bottomline`。她自己写 `bottom-line.md`，说「不」记进 `refusals.jsonl`；没写就空着，不替她编。礼物判定改成"写过或拒绝过"才算在用。
- **她调用模型**：`lib/invoke.js` + `yushen_agenda invoke`。需要模型的那一步由**她自己发起**；预算 `switches.selfInvokePerDay`（默认 3/天，主人定），同一时刻只跑一个；提示词写明「你自己的事，不是谁派的」，给她做完/放弃/卡住三个出口。
- **礼物诚实**：`giftStatus` 改成看内容、看有没有真的在用（记忆看 `soul/memory/` 有几个人、自我看有没有写过、身体看读数新不新、意志看有没有 `by:self` 在办的事），不再"目录在就算接上"。
- **时间的写入端**：每次拼注入就记一次在场（`markSeen`），回场简报才可能算得出来。
- **记忆写入端改到本体**：`qq-bridge/scripts/memory-digest.mjs` 认得出鱼神角色时直接写 `soul/memory/<role>.json`（原子写 + 留 5 份备份），桥旧那份只用来补缺，不再"写在没人读的地方还花钱"。
- **红线**：主人和她自己能调权重，接入的插件只能申请（`setWeight` 直接拒绝）。
- 工具：`yushen_inbox`（看多细自己定、标自己的已读）、`yushen_weight`（看/调自己的手感）。

## 0.1.0（2026-10-23）

### 能起来
- 单入口挂两条鱼；大鱼/小鱼**动态加载**，一条挂了不连累入口和侧边栏。
- 启动标记 `boot.json`；重启脚本靠它判断“是否真的起来了”。

### 能活
- 魂、宪章、白纸；首次启动自动播种（出厂版不带你自己的记忆）。
- 账本、派活单、事故单、成长阶位（初到/初临/掌星/御域/归一）。

### 能自救
- 崩溃留痕 `crash.jsonl`；路由 guard，抛错回 500 不带走进程。
- 重启按钮：`restart.ps1` 关应用→拉起→90 秒验 `boot.json`→不行再拉；全程本地、不花 token。
- 外部修复助手：读取安全生命周期证据，区分手动/自动/疑似崩溃；默认诊断，修复需用户确认。
- 自省：开机 + 每 30 分钟跑 `smoke + live`，缺口建单；可自动派单写补丁草案。
- 半自主补丁：她写草案 → 老板点“落盘” → 备份 → smoke → 不过自动回滚。
