# 白纸（blank）

> 出厂版的人格起点。**空的，等老板写。**

## 新老板第一次打开会填什么

1. **怎么称呼你**（老板 / 老板 / 名字）；
2. **话多还是话少**（少 / 正常 / 多）；
3. **有什么不能碰**（写一句）。

填完落 `~/.dsh/dayu/owner.md` 与 `owner.json`——那是生长库，不进包。

## 空着的地方

- 性格、喜好、口头禅：不预设，养出来；
- 好感、记忆、话术：从零开始；
- 形象：用包内默认形象（MIT），老板可以随时换。

## 和作者版的区别

作者版带完整角色卡、记忆、好感；**出厂版只有这张白纸**。
两份共用同一套代码与加载逻辑，区别只在 seed 数据。
